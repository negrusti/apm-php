CONNECT YOUR WORDPRESS SITE

A direct line to your application.

Use the stock New Relic PHP module with the Relay PHP daemon. No additional WordPress plugin is required.

01

Configure the Relay daemon

Install the relay-php-daemon package on the PHP server. Set the backend URL in /etc/relay-php-daemon/daemon.cfg, then start the service. HTTP is for trusted private networks; HTTPS verifies the server certificate.

Connect the PHP module
Use the ingestion key created for your site.
02
Restart PHP and generate traffic
Restart PHP-FPM or Apache after changing the configuration. Open a few WordPress pages and allow a harvest cycle, normally about one minute.
03
Explore the breakdown
Your application appears once its first metric batch is stored. Plugin/theme and hook metrics include call counts, total duration, and self time.
